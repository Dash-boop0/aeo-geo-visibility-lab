# Sample data — SYNTHETIC, illustrative only

Every file in this folder is **synthetic**. The brands (Ledgerly, BillBright, InvoiceNest, PayTrail) are
fictional, all domains are reserved `example.com` / `example.org` / `example.net` domains, and every
observation was generated by a seeded pseudo-random process (`src/lib/sample.js`, seed `20261019`).
**None of it is a real AI-assistant answer, mention or citation**, and it must not be quoted as evidence of
any brand's visibility.

The generated files are rebuilt with `npm run sample-data` (or `node scripts/generate-sample-data.mjs`);
a test fails if they drift from the generator.

| File | What it is |
|---|---|
| `questions-template.csv` | Empty-ish template for your own question set (2 example rows to replace). |
| `observations-template.csv` | Template for logging observations (1 example row to replace). |
| `sample-questions-synthetic.csv` | The 30 buyer-intent questions of the illustrative project (8 discovery, 8 informational, 7 comparison, 7 purchase). |
| `sample-observations-synthetic.csv` | 158 synthetic observations: Assistant A and B on 2026-09-07 and 2026-10-05, Assistant C on 2026-10-05 only (a deliberate gap), plus a second run of the 8 discovery questions on Assistant A, 2026-10-05. |
| `sample-project-backup-synthetic.json` | The same sample project as a JSON backup, for testing **Restore**. |

## Questions CSV columns

| Column | Required | Notes |
|---|---|---|
| `question` | yes | The exact question text. Duplicates (ignoring case, spacing, trailing `?`) are skipped. |
| `intent` | yes | One of `discovery`, `informational`, `comparison`, `purchase` (case-insensitive). |
| `question_id` | no | Letters, numbers, `-`, `_`. Generated as `q01`, `q02`… when blank. |
| `notes` | no | Free text. |

## Observations CSV columns

| Column | Required | Notes |
|---|---|---|
| `date` | yes | `YYYY-MM-DD`, must be a real date. |
| `platform` | yes | Your label for the assistant/surface, e.g. `Assistant A`. Keep labels consistent between rounds. |
| `question_id` or `question` | one of them | Linked by id first, then by exact question text. An unknown question is created only if `intent` is also given. |
| `intent` | no | Only used to create a missing question. |
| `run` | no | Whole number 1–99, default 1. Use 2, 3… for repeated runs of the same prompt on the same day. |
| `prompt` | no | The exact prompt sent. Defaults to the question text (with a warning). |
| `settings` | no | Model/mode/locale/signed-in state — anything that could change the answer. |
| `answer_summary` | no | A short neutral summary of the answer. |
| `brands_mentioned` | no | Brand names or aliases separated by `;`. Brands must already exist in the project; unknown names are ignored with a warning. |
| `cited_urls` | no | `http(s)` URLs separated by `;` or spaces. Invalid URLs are ignored with a warning. |
| `cited_domains` | no | Domains named as sources without a link, separated by `;`. |
| `observation_id`, `notes` | no | `observation_id` is ignored on import (new ids are assigned). |

Rows with the same question + platform + date + run as an existing observation are skipped, so re-importing a
file is safe. Files are UTF-8, comma-separated, RFC 4180 quoting; a BOM and Windows line endings are fine.
